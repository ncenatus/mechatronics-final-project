# Automatic Temperature-Controlled Fan

**ECGR 2161 – Mechatronics I**  
UNC Charlotte | Fall 2026

## Project Overview

The objective of this project is to design an automatic temperature-controlled fan using an Arduino Uno R3. The system will measure the surrounding temperature and automatically adjust the fan speed based on temperature readings.

## Equipment

- Arduino Uno R3
- DHT11 temperature and humidity sensor
- L293D motor driver
- DC motor with fan blade
- 16×2 LCD display
- Two 10 kΩ potentiometers
- Breadboard
- Jumper wires
- External power supply
